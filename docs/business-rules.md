# 💼 PartnerOn v1.0 Business Rules Specification

PartnerOn 시스템의 비즈니스 규칙 및 보안 통제 정책 문서입니다.

---

## 🔐 1. 4단계 직급별 메뉴 권한 (RBAC: Role-Based Access Control)

| 직급 구분 | 칭호 | 권한 범위 및 특징 |
| :--- | :--- | :--- |
| **`OWNER`** | 관리자 (대표) | 시스템 전체 슈퍼유저. 사업장 설정, 2FA 강제 통제, 직급별 권한 관리, 승인 기기 통제 전체 접근 가능. |
| **`ADMIN_STAFF`** | 관리자 (사무직원) | 사무 관리자. 고객사 등록, 계약 관리, 장비 등록 및 관제 조회 권한 보유. |
| **`SALES`** | 영업 | 영업 담당자. 담당 고객사 영업 활동, 견적 관리, 장비 현황 조회 권한 (보안 설정 수정 불가). |
| **`CE`** | Customer Engineer | 현장 정비 엔지니어. 장비 정비 이력 등록, 소모품 교체 및 관제 상태 조회 전용. |

## 🛡️ 2. 2FA (2차 인증) 종합 통제 메커니즘

1. 유저의 2FA 적용 여부는 `user.requires_2fa()` 메서드를 통해 판단됩니다:
   * **개인 2FA 활성화**: `user.is_2fa_enabled == True`
   * **사업장 직급별 2FA 강제 정책**: `workplace.enforce_2fa_owner` 등 해당 직급 강제 켜짐 상태
2. 2FA 필수 대상자는 ID/비밀번호 통과 후에도 JWT 토큰 대신 `require_2fa: true` 패킷이 리턴되며, 프론트엔드의 `Verify2FAModal` 모달에서 TOTP 또는 6자리 이메일 OTP를 입력해야 최종 JWT가 발급됩니다.
3. 이메일 OTP 코드는 발송 후 **5분 자동 만료**되며, 1회 검증 완료 즉시 DB에서 소멸됩니다.

---

## 🤝 3. 8자리 고유 구성원 초대 시스템 (Member Invitation System)

1. 대표(`OWNER`) 또는 사무직원(`ADMIN_STAFF`)은 신규 임직원을 이메일 초대할 수 있습니다.
2. 시스템은 고유한 8자리 알파벳/숫자 조합 초대 코드(예: `INV-8A9F2K`)를 발행합니다.
3. 초대 코드는 생성 후 **24시간 동안 유효**하며, 만료 시 대표가 재발송(`Re-invite`)할 수 있습니다.
4. 초대를 받은 유저는 초대 링크를 클릭하여 가입 시 본인의 사업장 및 지정된 직급으로 즉시 자동 소속됩니다.

---

## 🤖 4. 에이전트 3가지 스캔 자동 분기 규칙

1. **조건 1 (등록 장비 0대 상태)**: 백엔드 `target_serials` 0대 ➔ 로컬 네트워크 서브넷(.1~.254) **풀 스캔 (Full Scan)**.
2. **조건 2 (CLI/API 파라미터 수신)**: `--scan-unregistered` / `-u` 수신 ➔ 서브넷 **풀 스캔 (Full Scan)**.
3. **조건 3 (정기 수집 동작)**: 정식 등록 기기 존재 시 ➔ 0.5초 초고속 **핀포인트 스캔 (Pinpoint Scan)**.
